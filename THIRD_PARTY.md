# Libraries and assets

Runtime helpers: GLAD 0.1.36 (OpenGL function loader), FreeGLUT (window/input),
GLM 1.0.3 (matrix/vector maths), stb_image (PNG loading). The renderer is our own
OpenGL code. GLFW is bundled in the original repository but unused.

- FreeGLUT: https://freeglut.sourceforge.net/ — permissive MIT-style license,
  reproduced in `Libraries/include/GL/freeglut_std.h`.
- GLM: https://github.com/g-truc/glm — MIT or Happy Bunny License; see upstream
  `copying.txt`.
- stb_image: https://github.com/nothings/stb — MIT or public-domain alternative;
  license text is included at the end of the bundled header.
- GLAD: https://github.com/Dav1dde/glad/tree/v0.1.36 — MIT; generated bindings
  also include Khronos API definitions. See upstream license and the copyright
  notice in `Libraries/include/KHR/khrplatform.h`.

All active character and enemy meshes are assembled from cubes in our source.
The three active arena textures are original procedural images generated by
`Assets/generated/generate_textures.py` and distributed under CC0 1.0; see that
directory's `LICENSE.txt`. Their source URL is
https://github.com/MasterDiyar/FinalProjectGraphics/tree/feature/battle/Assets/generated

Older `Assets/grass.png`, `road.png`, `wall.png`, `hero.png` and the disabled OBJ
are not used by this submission. Their provenance was not established, so the
submission ZIP excludes them. Optional OBJ loading remains in the source; the
submitted build uses the procedural hero. Do not add an external model without
also supplying its redistribution license and source.

solely spelling corrections. The report acknowledges this assistance. Each team
